# Drone Simulation

A Unity-based drone simulation developed to explore rigid-body motion and basic UAV control using a physics-based environment.

## Overview

The project represents a drone as a rigid-body system in Unity. A C# control script was used to simulate basic drone movement through **roll, pitch, and yaw** inputs.

The project also explored the use of articulation and physics concepts while developing the drone model.

## Key Concepts

* Rigid-body physics
* Roll, pitch, and yaw
* UAV motion
* 3D simulation
* C# scripting
* Unity physics

## Tools

* Unity
* C#
* Ubuntu/Linux

## Purpose

The project was developed to understand the relationship between UAV control inputs and the resulting motion of a drone in a simulated physics environment.

## Files

The repository contains the Unity project files, scripts, models, and assets used for the simulation.
